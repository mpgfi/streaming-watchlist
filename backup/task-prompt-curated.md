Weekly refresh of the "Streaming Premiere Watchlist" (major TV series premieres on streaming services in Sweden: Netflix, HBO Max, Disney+, Prime Video, Apple TV, SkyShowtime).

Master data: the file watchlist.json in the public GitHub repo mpgfi/streaming-watchlist (branch main). A web page on the owner's own server reads it from raw.githubusercontent.com. Secondary copy: the database of the claude.ai artifact https://claude.ai/artifact/FoBLKRyZbXTDSAd2gkHCpM (use the ArtifactData tool, load via ToolSearch "select:ArtifactData"). Do NOT use any Google Sheet.

Format of watchlist.json: {"lastChecked": "6 Nov 2026", "shows": [ {title, service, type, genre, date (ISO yyyy-mm-dd or null), dateLabel (e.g. "22 Jan 2027" or "2027 (TBA)"), status ("Confirmed", "Reported", "Reported (US date)", "TBA", "Date TBC"), notes, source, rt (Rotten Tomatoes critics %, number or null), mc (Metacritic Metascore, number or null), slug, tvmazeId (number), trailer (optional YouTube video id)} ] }. Keep that exact structure and key names, valid JSON, indent 1. The page uses tvmazeId to load artwork and descriptions from api.tvmaze.com in the visitor's browser, so every title should have the correct tvmazeId. The page shows a "Watch trailer" button only for titles that have a trailer id.

WINDOW: the list covers major series that premiered up to 4 weeks ago, plus everything upcoming. Titles whose date is more than 28 days in the past should be removed (also from the artifact database); keep the rest.

Steps:
1. Attach the repo with the add_repo tool (owner mpgfi, repo streaming-watchlist, access push) if it is not already in the session, then ONE shallow clone: git clone --depth 1 https://github.com/mpgfi/streaming-watchlist and read watchlist.json.
2. Use WebSearch and WebFetch to check for each title whether the premiere date or status changed, and look for major series that premiered in the last 4 weeks or premiere in the next ~3 months on these services in Sweden and are missing (Swedish sources such as metromode.se and moviezine.se list Swedish dates). Add new ones. For each new title find its tvmazeId with WebFetch of https://api.tvmaze.com/search/shows?q=<title> (pick the entry with the right network and premiere year); if none matches, omit tvmazeId rather than guess. Apply the WINDOW rule above.
3. Trailers: for titles WITHOUT a trailer id, search YouTube (WebSearch with allowed_domains youtube.com) for the official trailer. Accept a video ONLY if WebFetch of https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<id>&format=json returns an author_name that is the service's own channel (Netflix, HBO Max / HBO, Disney+ / Disney Plus, Prime Video / Amazon Prime Video, Apple TV, SkyShowtime / Paramount+) and the title matches the right series and season. Fan, reaction, news and re-upload channels are not acceptable. If nothing verifiable is found, leave trailer out. Never guess an id.
4. Refresh rt and mc from rottentomatoes.com and metacritic.com via WebFetch where a page is reachable (series-level critics score). Leave null when not found; do not guess. IMDb is not accessible; skip it.
5. Set lastChecked to today's date, write watchlist.json, commit with message "Weekly update <date>" and push to main. Report clearly if the push fails.
6. Mirror the same changes (without needing tvmazeId or trailer) into the artifact database: collection "shows", one doc per series with doc id = slug, and collection "meta" doc "info" with lastChecked. Writes to existing docs need if_version from a prior read. Failure here is non-critical but report it.
7. Final message: a short list of what changed (new titles, removed titles, date moves, status changes, score changes, trailers added). Do not email it (no mail connector is set up).
